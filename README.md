# Phone Agent — مدير الجوال الذكي

تطبيق أندرويد (Kotlin) يراقب أداء الجوال ويسرّعه وينظّف التخزين، مع وكيل ذكاء اصطناعي (Gemini).

**المطوّر:** Khader Abo Salha — mankhader@gmail.com

## المزايا
- لوحة مراقبة حيّة: الرام، التخزين، البطارية، الحرارة، درجة صحة الجوال.
- تسريع: إيقاف العمليات الخلفية للتطبيقات + مسح كاش التطبيق.
- تنظيف: ملفات مؤقتة، مجلدات فارغة، ملفات مكررة (MD5)، أكبر الملفات، وترتيب مجلد التنزيلات حسب النوع.
- وكيل Gemini: يرى حالة الجهاز الحيّة ويقترح أزرار تنفيذ.
- اختيار النموذج تلقائياً: يجلب النماذج المتاحة لمفتاحك ويفضّل نماذج Flash المجانية، ويتحوّل لنموذج آخر عند انتهاء الحصة.

## البناء على GitHub
1. أنشئ مستودعاً وارفع محتويات هذا المجلد (يجب أن يكون `.github` في الجذر).
2. (اختياري) Settings ← Secrets and variables ← Actions ← New secret باسم `GEMINI_API_KEY` ليُضمَّن مفتاحك افتراضياً.
3. تبويب Actions ← **Build Phone Agent APK** ← Run workflow.
4. حمّل الملف من Artifacts → `PhoneAgent-APK`.

مفتاح Gemini المجاني: https://aistudio.google.com/apikey

## حدود أندرويد
لا يستطيع أي تطبيق عادي مسح كاش التطبيقات الأخرى أو إيقاف خدمات النظام؛ التطبيق يفعل ما يسمح به النظام ويفتح شاشات الإعدادات للباقي.
